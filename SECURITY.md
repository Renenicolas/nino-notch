# Security Policy

## Reporting a Vulnerability

Nino Notch is a fork of [Boring Notch](https://github.com/TheBoredTeam/boring.notch). Security bugs in this fork are handled here, not upstream.

To report a security issue, use the GitHub Security Advisory ["Report a Vulnerability"](https://github.com/Renenicolas/nino-notch/security/advisories/new) tab. Do not open a public issue for it.

If the bug is in upstream Boring Notch code, please also report it to [TheBoredTeam](https://github.com/TheBoredTeam/boring.notch/security/advisories/new).

Report security bugs in third-party dependencies to the person or team maintaining that package.
